# Generation Packet 经验规则

## 参考图层级

推荐按以下层级组织参考：

1. 授权角色参考：正面/侧面/背面、脸或头盔、颜色、武器/关键道具。
2. 授权场景参考：地点、时间、天气、光线、建筑、空间密度。
3. 已批准 storyboard grid/关键帧：构图、blocking、camera side、screen direction、主体大小。
4. 图像模型生成的关键帧：视频生成的最终视觉目标。
5. 文本 prompt：运动、节奏、情绪、连续性和禁止项。

## 图像关键帧 Brief

好的图像 brief 应该写清：

- 哪些角色参考必须保留。
- 哪些场景参考必须保留。
- 哪张 storyboard/关键帧控制构图。
- 哪些 shot-plan 信息不能改：主动方、目标、运动方向、camera side、轴线。
- 避免项。

这些镜头建议生成首尾帧或关键帧：

- 拉手、搀扶、抓取等手部接触。
- 对话正反打，尤其需要稳定轴线/视线。
- POV 或不常规机位。
- 多角色动作。
- 爆炸、烟尘、强特效容易抢主体的镜头。

## 视频 Prompt

好的视频 prompt 应包含：

- 片段目标。
- 角色和身份约束。
- 镜头顺序和时长。
- 运动与摄影机行为。
- 连续性和 negative constraints。

不要把太多故事 beat 塞进一个视频片段。身份、方向或动作因果脆弱时，拆短。

## 漫剧/AI 动画经验

- 对话段优先保证角色一致性、视线方向、口型/微动作节奏，而不是大幅运动。
- 正反打应成对准备参考图，保持同一轴线和相反机位。
- 关键情绪镜头最好先生成单帧定稿，再做视频。
- 动作段不要追求完整动作物理，先锁定起点、接触点、结果帧。
- 镜头 prompt 中明确“谁动、向谁动、从哪到哪”，避免模型自行反转主被动。
- 复杂背景、爆炸、烟尘类画面要明确主体优先级，避免背景特效抢走角色。
- 同一角色在多个片段中使用同一组身份参考图和同一套命名。

## 一致性检查

发送视频生成前检查：

- 角色颜色、轮廓和设定图一致。
- screen direction 和批准的 storyboard/关键帧一致。
- 对话轴线稳定。
- 主动方和目标正确。
- 危险源和撤离方向正确。
- 背景连续性不违背场景。
- 图像关键帧符合镜头目的。

## 文档新鲜度

模型 API 和参数变化很快。真正接 API 前，重新查：

- OpenAI 图像生成模型/API 当前用法。
- Seedance/火山引擎视频生成 API 或网页限制。
- 支持的参考图数量、尺寸、比例、格式和时长。

如果当前环境无法获取文档，只输出 prompt 和 packet 文件，不声称 API 参数准确。

## 视频 Prompt 编写规则

视频模型的上下文注意力非常有限，每条 prompt 是独立上下文。以下规则适用于所有视频 prompt。

### 核心原则：精简至上

任何多余的、抽象的、矛盾的描述都会降低成功率。能删就删，能短就短。

### 参考图描述：只写"是什么"，不写"长什么样"

参考图本身已包含视觉信息，prompt 只需标注身份：

- 角色："参考图X：女性角色<名字>，<性格气质>。"（气质补充参考图中体现不出的神态线索）
- 场景："参考图X：场景——<场景名>。" 
- 构图："参考图X：多宫格分镜构图参考，保持其镜头顺序、景别和角色位置。"

**不要重复描述参考图中已有的发色、服装、房间布局等视觉细节**——这会导致与参考图矛盾，降低成功率。

### 禁止添加模型不懂的抽象概念

"BaldrSky世界观""赛博朋克""90年代动画质感"——模型不理解这些。如果影响画面，转为具体的可见描述（光线、调色、建筑特征）；否则删除。

### 禁止重复参考图已覆盖的信息

角色外观由角色参考图锁定，场景布局由场景参考图锁定。prompt 中不要另起段落复述。**尤其注意**：不同景别看到的场景范围不同，近景镜头中不可见的家具不要在 prompt 中描述。

### 对白格式

对白用双引号包裹，紧接动作描述之后。必须写具体台词文本，不能只写 voice id 或内部符号：

```
"おはようございます、甲さん"
```

- 正确：`蕾低声说："私は……料理が苦手です"。`
- 正确：`厨房方向传来菜ノ叶的画外音："危ない！"。`
- 错误：`播放 v10200075`、`按 voice_id v10200075 对口型`、`说这句台词`。

voice id 只用于后期匹配原游戏语音，保存在 `dialogue_timing[].voice_id` 或任务 metadata，不进入发给图像/视频模型的 prompt 正文。

### 镜头运动：单语言

中文或英文，不要写成"推近（push in）"。

### 禁止项：只写参考图覆盖不到的

参考图已锁定外观和场景。禁止项写真正超出一张参考图范围的东西：

- "不要在画面中生成字幕或文字"
- "不要生成语音或音效"

**不要写**"不要改变发色""不要改变房间布局"——参考图已覆盖这些。

### 位置关系：具体，不抽象

- 写"蕾在画面左侧，甲在画面右侧"——具体
- 不要写"保持跨镜头一致"——模型不知道其他镜头的存在

## 漫剧式生成 Prompt 参考结构

以下结构仅供参考。**如果某层信息已由参考图覆盖，则该层应省略。**

```text
参考图1：女性角色A，气质干练。
参考图2：男性角色B。本片段中B刚睡醒，头发凌乱。
参考图3：场景——酒店房间清晨，暖光从右侧窗射入。
参考图4：多宫格分镜构图参考。

风格：动漫/漫剧，16:9画幅。无字幕。视频静音。

[00:00-00:03] 近景过肩。A在画面左侧，背光形成轮廓光，微倾身说话。"おはようございます"。镜头轻微手持。

[00:03-00:06] 近景。B正面，头发凌乱，打哈欠，眼神困倦。"ああ、おはよう……"。镜头缓慢推近。

禁止：生成字幕或文字；生成语音或音效。
```

## 参考图使用策略

- 角色三视图：只负责身份、比例、颜色、装备。
- 场景三视图/概念图：只负责环境连续性。
- storyboard grid/关键帧：只负责构图、机位、走位、动作方向。
- 生成关键帧：负责最终画面质量和视频模型的首尾状态。

不要让一张图承担所有职责。职责越混乱，模型越容易在身份、构图和风格之间折中出错。

## 漫剧对话段建议

- 单个片段控制在一个明确情绪 beat 内。
- 正反打成对生成关键帧，保持同一背景逻辑和轴线。
- 对话镜头动作小，靠眼神、头部、肩部、烟尘和轻微手持维持生命感。
- 重要台词优先稳定角色脸/头盔方向，不要同时安排复杂走位。

## 动作/战斗段建议

- 不追求完整动作过程，先锁定三帧：准备、接触、结果。
- prompt 明确主动方和受动方，例如“角色B从右侧冲向角色A并拉起对方”，不要只写“两人靠近”。
- 多角色战斗尽量拆成短片段，避免一个片段同时包含冲刺、射击、倒地、救援、逃离。
- 爆炸、烟尘、火光都要写主体优先级，否则容易抢走角色。

## 来自外部案例的补充规则

参考 `external_prompt_research.md`。当前结论：

### Seedance 片段 prompt 推荐结构

```text
【风格】动画/漫剧/电影风格、色调、镜头质感
【时长】例如 10 秒或 15 秒
【全局要求】角色一致性、画幅、字幕/口型、禁止项

[00:00-00:03] 镜头 1：景别 + 主体 + 动作 + 情绪 + 镜头运动
[00:03-00:06] 镜头 2：景别 + 主体 + 动作 + 情绪 + 镜头运动
[00:06-00:10] 镜头 3：结果/反应/转场

【避免】身份漂移、跳轴、错方向、背景抢主体
```

### GPT-image 关键帧推荐结构

```text
Goal: 生成某镜头首帧/尾帧/角色设定表
Aspect ratio: 16:9 / 9:16 / 3:4
Use references: 角色设定图、场景图、storyboard 构图图
Scene: 场景和光线
Subject: 主体角色和姿态
Composition: 景别、前景/中景/背景、镜头方向
Details: 装备、表情、动作状态、烟尘/特效
Constraints: 保持身份、颜色、轴线、运动方向
Avoid: 不要互换角色、不要改变服装、不要遮住主体
```

### GPT-image 多宫格分镜推荐结构

在人工 review 之后、视频生成之前，建议先生成一张多宫格镜头引导图。给图像模型的 prompt 必须自足，不要写“参考上面的预览”、`shot_plan`、`更接近真实参考图` 这类依赖上下文或相对比较的词。

```text
Goal: 生成 6/9 格黑白或低饱和分镜草稿，用于检查构图、轴线、动作起止和角色一致性
Style: 清晰线稿、灰阶阴影、少量角色主色标识、分格明确，不追求精修插画质感
Use references: 角色设定图、场景图、构图参考图
Layout: 16:9 contact sheet，按时间从左到右、从上到下
Per panel: 景别、主体、前景/背景、动作起止、镜头运动感
Dialogue axis: 保持同一 camera side，不交换左右位置
Avoid: 不要写内部 shot id，不要输出说明文字，不要跳轴，不要交换角色
```

它不是最终画风定稿；成本低于视频，适合暴露视频前的构图和一致性错误。

### 角色设定图/三视图建议

先为核心角色生成或整理 reference sheet：

- 正面、侧面、背面
- 头部/脸/头盔细节
- 表情或情绪变化
- 服装/机甲/武器拆解
- 色板
- 简短世界观说明
- 干净背景，避免复杂构图干扰身份参考

### 漫剧短视频建议

- 每个片段只解决一个情绪或动作 beat。
- 对话段可以写“口型与字幕逐字一致”，但仍要控制台词短句。
- 强情绪段写清微表情、眼神、停顿、雨/烟/光的辅助运动。
- 动作段写清“静止 -> 爆发 -> 碰撞 -> 结果”，并明确碎片/烟尘是辅助，不是主体。
