# 剧情改编大纲（Script Adaptation Outline）

本 skill 用于详细分镜/shot planning 之前：把很长的原始游戏章节改编成较短、可 review 的 `bsd_*.md` AI 动画脚本草稿。

目标不是直接写最终 `shot_plan`，而是在严苛时长和制作约束下，帮助用户决定改编应保留、删减、合并和强调什么。

## 核心前提

- 原作单章剧情可能约 1 小时；目标动画可能只有每集/每段约 5-7 分钟。
- 用户使用原作游戏语音素材，因此对白必须使用 raw 脚本中的原句和真实 voice id。
- raw 脚本常常不包含战斗细节；需要战斗时，要向用户询问或让用户补充战斗 beat。
- AI 视频生成不擅长多人同屏、精确手部接触、密集动作和复杂空间连续性。
- `bsd_*.md` 是供人工 review 和后续 `storyboard-to-project` 使用的规划稿；应保持粗粒度，但必须对制作有用。

## 需要检查的输入

1. 原始脚本：`bsd_anime_script/raw/*.txt`。
2. 既有章节草稿：`bsd_anime_script/bsd_*.md`，用于确认格式、衔接和已覆盖剧情。
3. 素材描述：`assets/chars/*.yaml` 和 `assets/scenes/*.yaml`，用于判断角色/背景素材缺口。
4. 可选规范：
   - `docs/adaptation_outline_spec_v1.md`
   - `docs/shot_plan_spec_v1.md` 只用于下游兼容，不在本 skill 中写详细 shot。

## 工作流

### 1. 阅读并分段 raw 脚本

- 根据 field/background 标记、角色登场和事件转折识别主要场景。
- 提取候选原作语音：角色、voice id、原文台词。
- 标记只能靠旁白理解的信息：这些信息可能需要视觉替代表达、台词选择，或用户补充战斗 beat。
- 标记成人/露骨、多人拥挤或视觉成本高的内容，优先建议删减、暗示或重构。

### 2. 只追问缺失且具体的问题

在提出最终裁剪方案前，检查 `references/question_checklist.md`。不要询问用户已经回答过、或可从现有文件明显推断的问题。

读过相关 raw 文本后，优先提出具体问题：

- 询问哪些具体剧情点必须保留，或先提出候选清单让用户确认。
- 询问每个候选场景具体要让观众理解什么、感受到什么。
- 遇到难生成场景时，说明难点并带着推荐简化方案询问。
- raw 文本跳过战斗细节时，询问战斗 beat。
- 判断素材缺失后，询问用户是后续补素材，还是改写到现有素材可覆盖的场景。

不要问“剧情优先还是情感优先？”这类抽象问题；必须转化为具体场景选择。

### 3. 先提出短改编大纲

写文件前，先给用户一个紧凑、偏决策的大纲：

- 建议拆成哪些 `bsd_*.md`，每段大致时长。
- 场景列表：地点、角色、功能、保留的关键台词/事件、删减或压缩内容。
- 转场方案，尤其是合并原作场景或跳过吃饭/移动等过场时。
- 制作风险：多人同屏、战斗、手部接触、素材缺口、空间关系不清等。
- 需要用户确认的开放问题。

如果用户需要持久化大纲，可按 `docs/adaptation_outline_spec_v1.md` 写 `adaptation_outline.yaml`。否则在确认前用聊天文本讨论即可。

### 4. 用户确认后再写 `bsd_*.md`

用户确认场景切割和改编方向后，才在 `bsd_anime_script/` 下创建新的草稿文件。

遵循：

- `references/bsd_md_format.md`
- `assets/bsd_script_template.md`

### 5. 根据用户 review 迭代

用户 review 草稿后：

- 除非用户明确要求，否则保留已认可的场景和台词。
- 只修改受影响的 `bsd_*.md`；如果用户要求非破坏式迭代，则创建新版本。
- 删除没有分镜价值的小说式抒情或心理描写。
- 增删台词后重新估算时长。
- 场景或角色变化后重新检查素材需求。

## 输出边界

可以做：

- 选择并说明保留原作语音台词的理由。
- 为了制作可行性和剧情连续性合并场景。
- 添加简洁的关键镜头、表情、站位、转场说明。
- 标出哪些战斗内容需要用户补充设计。
- 标出缺失的角色/场景素材。

不要做：

- 编造 voice id 或新的日文有声对白。
- 在本 skill 中写视频模型 prompt 或 `shot_plan.json`。
- 把脚本写成带内心独白和文学修辞的小说。
- 添加素材或游戏背景中没有的画面细节。
- 添加改变路线焦点或人物关系的亲密动作。
- 在 `bsd_*.md` 中写“同前”“沿用上一段”这类不自包含描述。
